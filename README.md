# CareerAI 🚀

AI-Powered Career & Resume Intelligence Platform.

CareerAI is a full-stack web application that analyzes resumes and provides a career intelligence report based on detected skills.

## ✨ Features

- 📄 PDF resume upload
- 📝 DOCX resume upload
- 🔍 Resume text extraction
- 🧠 Skill detection
- 📊 Skill match score
- ✅ Skills found
- 📈 Missing skills / growth areas
- 🤖 CareerAI summary
- 🎨 Modern animated UI/UX
- ⚡ React + Flask full-stack architecture

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- JavaScript
- CSS

### Backend
- Python
- Flask
- Flask-CORS
- PyPDF2
- python-docx
